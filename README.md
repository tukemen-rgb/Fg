# SIDRA STUDIO 全社戦略

このリポジトリは、SIDRA STUDIO（シドラスタジオ）の経営判断を一元管理するためのものです。

## 結論

SIDRA STUDIOは、独立ゲームを中心に次の2つの経済圏をつなぐ会社として成長します。

- **GAMEYARD（ゲームヤード）**: 作品を見つける・遊ぶ・公開する「作品の経済圏」
- **CreatorYard（クリエイターヤード）**: 制作過程・知識・協力関係を流通させる「作る人の経済圏」

当面の最優先は、両サービスの機能追加ではなく、**GAMEYARDで実ユーザーと投稿作品を獲得すること**です。ユーザー実績がない状態でスポンサー営業を先行すると単価も成約率も低くなるため、2026年8月第2週をユーザー獲得、第3週をスポンサー営業開始の目安とします。

## 事業の順序

1. GAMEYARDの公開環境と主要導線を安定させる
2. 最初の投稿者とプレイヤーを手動でも獲得する
3. 利用実績・声・行動データを作る
4. CreatorYardへ制作者を送客し、Creator Partnerを検証する
5. 実績を根拠にスポンサー・広告主へ提案する
6. ゲーム販売、テンプレート、メンタリング等へ収益源を広げる

## 最重要指標

北極星指標はページビューではなく、**週次で遊ばれた投稿作品数**です。作品数、制作者、プレイヤーの3者が同時に増えているかを測れます。

直近の経営ゲート:

- 投稿完了率 50%以上
- 新規投稿作品 10本
- 週次アクティブプレイヤー 100人
- 投稿作品の累計プレイ 300回
- 制作者インタビュー 10件
- 再訪率または7日継続率を計測可能にする

この基準を満たすまでは、大規模なスポンサー営業や新規事業の追加を原則行いません。

## 意思決定原則

経営判断は次の順で評価します。

1. ユーザー満足への効果
2. 収益化までの速さ
3. 収益の最大化余地
4. 実行可能性
5. 他社との差別化

毎週、KPIに最も大きく効く課題を1つだけ全社最優先に指定します。
