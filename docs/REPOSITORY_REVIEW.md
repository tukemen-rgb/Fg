## 観察

### GAMEYARD

- 約21,907件の収集ゲーム、約25,581ページの静的生成という大きな供給基盤がある
- SEO/AIO、投稿、ウイルス検査、即時公開、管理、運用スクリプトまで実装範囲が広い
- 技術的完成度に比べ、独自投稿作品・利用者・継続利用の実績が次のボトルネック
- 機能追加より本番獲得と導線改善の限界効果が高い

### CreatorYard

- 「作る人」を中心とした思想とCreator Partnerの営業資料が整備されている
- GAMEYARDの広告商品とCreator Partnerを分離した判断は妥当
- 実利用・支払意思・提供工数の検証が必要
- GAMEYARDの投稿者を最初の顧客候補にすると獲得コストを抑えられる

### 公式HP

- ブランド、作品、問い合わせ、公開運用の土台がある
- 現状は直接集客より、スポンサーやパートナーが確認する信用装置として使うべき

### ゲーム・マーケティング群

- 複数作品と販売・集客調査が存在し、学習資産は多い
- 同時進行は完成・販売・検証を遅らせる危険がある
- 自社ゲームは「売る商品」であると同時に、GAMEYARD/CreatorYardの最初の成功事例として1作品へ集中する価値が高い

## 経営上の結論

SIDRA STUDIOはアイデア不足ではなく、集中と市場検証が課題です。次の投資単位はリポジトリや機能ではなく、ユーザー行動のボトルネックに置きます。

優先順位は以下です。

1. GAMEYARDの本番利用
2. 投稿者とプレイヤーの継続
3. CreatorYardへの横断
4. 小型スポンサー実証
5. 勝ち筋が確認できた領域の自動化・拡大
