# 制作者インタビュー（型と記録。実施は人）

経営ゲート条件「制作者インタビュー 10 件」の受け皿。
型の根拠は docs/research/case-studies.md の 5（Postmortem）・6（The Mom Test）。

## 運用規則

- **実施・連絡・依頼文の送信は人（社長）**。このファイルは台本と記録の器
- 記録は事実のみ。相手は**ハンドル名のみ**（本人が公開している範囲）で書き、
  本名・所属・連絡先は書かない（git 履歴は消せない）
- 発言の引用は**本人が同意した範囲だけ**。同意の範囲を記録に残す
- **「1 件」と数える条件 = 質問票を完走し、記録が完備していること**。
  数合わせの薄い聞き取りは数えない
- 謝礼の有無・金額はここで決めない（決めるなら人）

## 質問票 v1

意見や未来の話（「何があれば使いますか」）は聞かない。
**過去の行動の事実**だけを聞く。

1. 最近ゲームを公開したのはいつ・どこでしたか
2. その公開先はどうやって決めましたか
3. 公開までで一番時間を取られたことは何でしたか
4. （GAMEYARD を試した人）どこで詰まりましたか
   （試していない人）いま使っている場所で困っていることは何ですか
5. 公開後、感想や数字はどう見ていますか

締め（Postmortem 形式・同数で聞く）:

- 最近の公開で**良かったこと 3 つ**
- 最近の公開で**詰まったこと 3 つ**

## 記録テンプレート（1 件 1 節。新しいものを上に）

```
## <番号>. <日時> <ハンドル名>
- 経路: <どこで知り合い、どう依頼したか>
- Q1〜Q5 の回答: <事実のみ>
- 良かったこと 3 / 詰まったこと 3:
- 引用同意の範囲: <全文可 / 要約のみ / 引用不可>
- 学び: <1 行>
```
